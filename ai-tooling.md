# AI Tooling

## Tools Used

OpenAI Codex/ChatGPT was used during development to assist with implementation, debugging, setup guidance, and documentation for the Northstar HR Agent.

## How the Tools Were Used

- Drafted and revised Python code for ingestion, retrieval, agent workflows, MCP integration, web endpoints, and evaluation utilities.
- Helped diagnose test failures and refine code and test commands.
- Supported step-by-step environment, deployment, and CI/CD setup.
- Helped prepare project documentation, evaluation descriptions, and the demo script.

## What Worked Well

AI assistance accelerated routine implementation and made it easier to reason through unfamiliar integration details. It was useful for turning project requirements into concrete implementation steps, identifying likely causes of test failures, and improving documentation clarity.

## What Required Review or Correction

Generated suggestions were treated as drafts. The project owner reviewed code and documentation, corrected issues found during manual checks and automated tests, verified tool traces and citations, and reconciled inconsistent test counts, retrieval settings, and evaluation reporting before submission. The project owner remains responsible for the final implementation and its correctness.

## Validation

The project was checked with the automated test suite, MCP discovery and tool-call checks, local application runs, deployment health/readiness checks, and end-to-end workflow demonstrations. No AI-generated result was accepted as a substitute for these checks.
